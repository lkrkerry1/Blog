二分是最常考的知识点之一，当题目出现 `最大值最小`、`最小值最大` 或者答案或某个中间结果呈现 **单调性** 时可以考虑。这里的 **单调性** 指前段满足后段不满足或类似情况。此处模板均维护闭区间，即最终结果均有 $l=r$，且默认 `check` 函数在结果合法时返回 `true`。

## 情况一：最大最优情况（左端满足右端不满足）

这里容易写错的就是二分时中点应该向上取整（或者说向会修改的那一端取整）。

```cpp
while (l < r) {
    int mid = (l + r + 1) >> 1;
    if (check(mid)) l = mid;
    else r = mid - 1;
}
```

## 情况二：最小最优情况（左端不满足右端满足）

这个就没什么好说的了，别和上面的情况弄混就行。

```cpp
while (l < r) {
    int mid = (l + r) >> 1;
    if (check(mid)) r = mid;
    else l = mid + 1;
}
```
